## About the Project

I'm Subhankar Dey, a frontend developer based in Kolkata, India, focused on building modern, responsive, and user-friendly web applications.

This portfolio is my personal space on the web. It brings together my work, technical capabilities, certifications, and learning journey in one place, with an emphasis on clean interfaces, thoughtful interactions, and engaging visual design.

Rather than relying on a conventional template, the portfolio combines a warm, light visual identity with carefully designed layouts, subtle motion, and interactive elements.

## Highlights

- **Modern interface:** A clean, light aesthetic with a distinctive coral, apricot, and pistachio-inspired color palette.
- **Responsive experience:** Layouts designed for desktop, tablet, and mobile screens.
- **Interactive animations:** Motion and transitions designed to make the experience feel engaging without overwhelming the content.
- **3D and visual effects:** Interactive visual elements that add personality to the portfolio.
- **Project showcase:** A dedicated space for selected projects, technologies, and practical implementations.
- **Technical skills:** An overview of my frontend and full-stack development toolkit.
- **Professional journey:** Education, certifications, and milestones in my development journey.
- **Direct contact:** A simple email-based contact option without unnecessary forms.
- **Performance-conscious design:** A modern Vite build workflow and responsive assets.
- **Accessible interactions:** Semantic elements, clear navigation, and keyboard focus styling where implemented.

## Getting Started

You can run the project locally to explore the source code or make improvements.

### Prerequisites

- Node.js and npm
- Git
- A code editor such as Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sdey1122/YOUR-REPOSITORY-NAME.git
```

**2. Navigate into the project**

```bash
cd YOUR-REPOSITORY-NAME
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL printed in your terminal.

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The production output is generated in the `dist/` directory.

## Deployment

The portfolio is designed as a static frontend application and can be deployed without a custom application server.

My planned deployment setup is:

- **Source control:** GitHub
- **Hosting:** GitHub Pages
- **Custom domain:** `subhankardey.dev`
- **Build output:** `dist/`
- **Secure connection:** HTTPS

The production build can be published through GitHub Actions. The custom domain must also be configured in GitHub Pages and pointed to GitHub's Pages infrastructure through the domain provider's DNS settings.
